# Instituto Ipê Amarelo — Landing Pages

Site de landing pages do Instituto Ipê Amarelo (Anna Patrícia Chagas), publicado via Cloudflare Pages.

## Deploy
Cloudflare Pages conectado direto a este repositório GitHub. Qualquer `git push` na branch `main` publica em produção automaticamente. HTML puro, sem build step.
